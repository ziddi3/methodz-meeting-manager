Static deployment boundary

This remains a plain HTML, CSS, and JavaScript application. Browser-local storage is the default provider. There is no production endpoint, required runtime package, build command, automatic reminder, background synchronization, or service-worker access to meeting business data.

If a bounded snapshot is truncated, the page says so rather than presenting the partial scan as complete.
