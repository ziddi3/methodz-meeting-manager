Deployment boundary

Methodz Meeting Manager remains plain HTML, CSS, and JavaScript. Browser-local storage is the default provider. No production hosted provider, account system, backend, mandatory network connection, runtime package, or build command is required for core operation.

This task-focused application is separate from Method Hub and must not be deployed over hub.methodz.ca.
