Static deployment boundary

  • Plain HTML, CSS, and JavaScript. No build command or runtime package is required.
  • Browser-local storage remains the default meeting-record provider.
  • The home snapshot is read-only and runs only after an explicit operator refresh.
  • No automatic save, assignment, reminder, notification, archive, transfer, provider call, or synchronization is introduced here.
  • This task-focused application remains separate from Method Hub.
