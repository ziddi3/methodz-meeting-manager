# Methodz Meeting Manager v1.6.11 Changelog

## Added

- Read-only **Meeting Pulse** for live capture readiness.
- One-action navigation to the next incomplete meeting section.
- Cross-record **Follow-Up Review** for overdue, due-soon, unassigned, invalid-date, pending, in-progress, and completed tasks.
- Explicit source-meeting opening from a follow-up item.
- Explicit filtered CSV download.
- Portable review core with deterministic date classification.
- Panel-registry declarations for both new workspaces.
- Node and Chromium regression coverage.

## Preserved

- Meeting-record schema `1.6.0`.
- Plain HTML, CSS, and vanilla JavaScript.
- Direct-file operation and ordinary static hosting.
- Browser `localStorage` as the default provider.
- Explicit, user-controlled synchronization, transfer, acceptance, rollback, and export actions.
- Existing governance, recovery, signing, custody, and archive safeguards.

## Not introduced

- No backend or production provider.
- No credentials or authenticated-user claims.
- No background synchronization or automatic delivery.
- No silent record or task mutation.
- No framework, package runtime, or build requirement.
- No deployment over `hub.methodz.ca`.
