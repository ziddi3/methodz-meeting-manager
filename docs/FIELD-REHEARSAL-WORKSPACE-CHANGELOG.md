# Field Rehearsal Evidence Changelog

## 1.0.0

- added `rehearsal.html` as a dedicated static physical-device evidence workspace;
- added portable `field-rehearsal-core.js` with deterministic readiness and bounded metadata normalization;
- added explicit environment inspection without user-agent fingerprinting;
- added explicit metadata-only JSON evidence download;
- added structured Android, iOS, tablet, desktop, and two-device platform choices;
- added all eight required field-rehearsal outcomes;
- added aggregate panel-count and duration fields;
- added numeric GitHub blocking issue references;
- excluded meeting content, record identifiers, attendee names, signatures, storage keys/values, credentials, private keys, provider secrets, queue payloads, transfer contents, and free-form operator notes from generated evidence;
- added portable and Chromium coverage;
- added Workspace Home and static cache wiring;
- preserved app shell `1.6.12` and meeting-record schema `1.6.0`.
