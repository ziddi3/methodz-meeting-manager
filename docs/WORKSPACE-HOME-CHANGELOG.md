# Workspace Home Changelog

## 1.0.0

- Added `index.html` as the static repository-root launch surface.
- Added portable aggregate-only `workspace-home-core.js`.
- Added explicit browser-local snapshot refresh with no automatic record read on page load.
- Added lifecycle routes for Preparation, Meeting-Day capture, Decision Register, Meeting Outcomes, Archive Vault, Device Readiness, and package verification.
- Added complete/partial bounded-scan coverage messaging.
- Added phone-safe responsive layout and 44-pixel refresh control.
- Kept the existing PWA identity while changing the installed start route to the repository root.
- Added static service-worker cache entries for Workspace Home assets.
- Added portable, Chromium, privacy, deployability, and documentation coverage.
